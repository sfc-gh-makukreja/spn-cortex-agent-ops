# Credits

The lifecycle (develop, evaluate, gate, promote, monitor), the slide diagrams and the
patterns this template is built on come from **Srini** and **Neel** (the Snowflake
"agent lifecycle" lab and its reference CI/CD pipeline for a credit analyst agent).
This repository generalises those patterns so they can be applied to any existing
Cortex Agent. Mistakes in the generalisation are ours, not theirs.

Built to go with the NZ Partner "Winning demos and production agents" Lunch and Learn,
and designed to take the output of
[spn-demo-creator](https://github.com/sfc-gh-makukreja/spn-demo-creator) (or any other
agent) from a demo to production.
