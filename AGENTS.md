# Agent instructions for this repo

- Specs and semantic views in `agent/` are always written with **DEV** names
  (`<NAME>_DEV`, `AGENTS_DEV`). `ops render` rewrites them per environment. Never
  edit a TEST or PROD name into them.
- `dcm/` (except hand edits you have reviewed) is generated by `uv run ops generate`
  from `agentops.yml` and the adopted spec. Change the inputs, then regenerate.
- The agent is not a DCM object (DCM has no `DEFINE AGENT`). Versions go through
  `ops/release.sql` and `ops/promote.sql` only.
- Do not hand-write `CREATE AGENT`/`ALTER AGENT ... SET SPECIFICATION`. To export a spec
  use `cortex agent-studio agent-read`.
- The data is not managed here. Do not add data-loading code; point to `docs/naming.md`.
- Ask before running anything that changes Snowflake or GitHub. Never print tokens.
- Run `uv run pytest -q` before committing.
